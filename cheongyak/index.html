관심 표시 저장 연결

관심 표시를 부부가 같이 보려면, 이 저장소에만 쓸 수 있는 GitHub 토큰을 한 번 연결합니다. 토큰은 잠근 상태로 저장되고 부부 비밀번호로만 꺼낼 수 있습니다. 채팅에는 보내지 마세요.

  1. GitHub → 오른쪽 위 사진 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Expiration: 1년 · Repository access: Only select repositories → home-dashboard
  3. Permissions → Repository permissions → Contents: Read and write (나머지는 그대로) → Generate
  4. 나온 토큰(github_pat_로 시작)을 아래에 붙여 넣고 연결
