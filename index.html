    관심 표시 저장 연결

    관심 표시를 부부가 같이 보려면, 이 저장소에만 쓸 수 있는 GitHub 토큰을 한 번 연결해요. 토큰은 잠근 상태로 저장되고 부부 비밀번호로만 꺼낼 수 있어요. 채팅에는 보내지 마세요.

    1. GitHub → 오른쪽 위 사진 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. Expiration: 1년 · Repository access: Only select repositories → home-dashboard
    3. Permissions → Repository permissions → Contents: Read and write (나머지는 그대로) → Generate
    4. 나온 토큰(github_pat_로 시작)을 아래에 붙여 넣고 연결
    월 결산 하는 법
    매달 말일~다음 달 3일 · 각자 3분
    1. 뱅크샐러드 가계부 탭 → 위쪽 톱니바퀴 → 파일로 받기
    2. 기간은 지난달 1일~말일로 고르고 메일로 받기
    3. ⟦H⟧·⟦W⟧ 파일 2개를 Claude 채팅(내집마련 대시보드 프로젝트)에 올리기
    4. 변동비는 부부 가계부의 그달 합계만 함께 적어 보내기
    5. Claude가 잠가서 이 화면에 반영해요. 같은 주소 그대로 쓰면 돼요
    자산은 말일 기준이에요. 3일을 넘기면 내보낸 날을 기준일로 적어요. 다짐이나 목표를 바꾸고 싶으면 채팅에 알려주세요.
